## 🔧 Iconografía alternativa (estilo MiBus)

Si necesitas **íconos individuales** (no las imágenes PNG prediseñadas), usa estos sets con color `#205CA7` o `#FFFFFF` sobre fondo azul:

- **Lucide:** https://lucide.dev (recomendado, MIT)
- **Heroicons:** https://heroicons.com (outline, MIT)
- **Feather:** https://feathericons.com (MIT)
- **Font Awesome 6:** https://fontawesome.com (free + pro)

Estilo de ícono: flat, line, 1.5-2px de grosor.

## 💾 Descarga y uso local

Para usar los assets offline, descárgalos a la carpeta de trabajo:

```bash
# Crear carpeta de assets
mkdir "%TEMP%\opencode\mibus-YYYYMMDD-HHMMSS\ASSETS"

# Descargar logo principal (Windows)
curl -L -o "%TEMP%\opencode\mibus-YYYYMMDD-HHMMSS\ASSETS\logo.png" "https://www.mibus.com.pa/wp-content/uploads/2019/03/logo-1.png"
curl -L -o "%TEMP%\opencode\mibus-YYYYMMDD-HHMMSS\ASSETS\logo-retina.png" "https://www.mibus.com.pa/wp-content/uploads/2020/05/retina-logo.png"
curl -L -o "%TEMP%\opencode\mibus-YYYYMMDD-HHMMSS\ASSETS\favicon.png" "https://www.mibus.com.pa/wp-content/uploads/2020/05/favicon.png"

# Descargar backgrounds
curl -L -o "%TEMP%\opencode\mibus-YYYYMMDD-HHMMSS\ASSETS\bg-stats.jpg" "https://www.mibus.com.pa/wp-content/uploads/2023/08/1920x566.jpg"
curl -L -o "%TEMP%\opencode\mibus-YYYYMMDD-HHMMSS\ASSETS\bg-newsletter.png" "https://www.mibus.com.pa/wp-content/uploads/2019/04/bg-Newsletter.png"
```

## ⚖️ Consideraciones legales

Los logos y assets son propiedad de **MiBus — Transporte Masivo de Panamá**. Su uso está limitado a:
- Materiales oficiales de la empresa
- Trabajos autorizados
- Materiales con fines informativos/transparencia

Para uso comercial o de marca blanca, solicitar autorización a MiBus.
