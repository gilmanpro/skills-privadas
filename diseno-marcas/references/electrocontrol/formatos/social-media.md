## Estilo visual por plataforma

### Instagram, TikTok, Facebook (más visual)

- **Dark mode SIEMPRE** (la marca es dark)
- Degradados vibrantes (cyan→purple→pink)
- Texto grande y bold
- Animaciones llamativas (zoom, transiciones)
- Emojis SÍ permitidos (en este formato, son parte del lenguaje nativo)
- Hashtags al final (10-15 relevantes): #IoT #Mecatrónica #ECU #Automatización #Panamá #Tecnología #Innovación #Electrocontrol

### LinkedIn (más profesional)

- **Dark mode también, pero más sutil** (menos degradados vibrantes, más slate sólido)
- Texto más pequeño, más denso
- Sin emojis excesivos (1-2 máximo, opcionales)
- Lenguaje profesional, orientado a B2B
- Énfasis en casos de estudio, resultados, expertise

### X / Twitter (texto primero)

- Diseño minimalista, el copy es el rey
- Imagen secundaria, da contexto
- Hashtags al final (2-3 máximo)

### YouTube (thumbnail llamativa)

- Texto GIGANTE (3-4 palabras)
- Contraste alto
- Color de marca pero que destaque
- Logo pequeño discreto

## Plantillas de contenido recurrentes

### 1. Post educativo ("¿Sabías que...?")

```
Diseño:
[ Fondo: degradado slate-900 ]
[ Logo esquina superior ]

¿SABÍAS QUE...?                              ← H1 degradado
═══════════════                               ← línea cyan

[Contenido del tip - 3-4 líneas en blanco/slate-300]

#IoT #Mecatrónica #Panamá                    ← hashtags
```

### 2. Post de proyecto realizado

```
Diseño:
[ Fondo: foto del proyecto con overlay oscuro 60% ]
[ Logo esquina superior ]

PROYECTO COMPLETADO                          ← H1 degradado
═════════════════════                        ← línea cyan

[ Nombre del cliente o del proyecto ]       ← 32pt
[ Servicio prestado (IoT, ECU, etc.) ]      ← 24pt slate-300

[ 3-4 bullets con resultados clave ]        ← bullets cyan

[Logo] + datos de contacto                   ← footer
```

### 3. Post de servicio destacado

```
Diseño:
[ Fondo: color del servicio (cyan/blue para IoT, etc.) ]
[ Logo esquina superior ]

ICONO DEL SERVICIO (grande, 200x200)          ← en gradiente del servicio

[ Nombre del servicio ]                      ← H1 degradado
[ Tagline del servicio ]                     ← slate-300

[ 4 features con check cyan-400 ]            ← lista de features

[ CTA: "Contáctanos → +507 6250-9318" ]     ← botón
```

### 4. Post de testimonio / caso de éxito

```
Diseño:
[ Fondo: degradado slate-900 → slate-800 ]
```
