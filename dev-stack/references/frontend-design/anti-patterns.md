# Anti-Patrones

Evita estos patrones comunes y usa las alternativas recomendadas para mantener una estética audaz y profesional.

| Evitar | Usar en su lugar | Por qué |
|--------|------------------|---------|
| Inter, Roboto, Arial, Space Grotesk | Playfair Display, Syne, Clash Display, Satoshi, Switzer | Las fuentes genéricas generan un look "AI slop"; las tipografías distintivas diferencian el diseño. |
| Gradientes púrpura sobre blanco | Gradientes con propósito, fondos oscuros + acentos vibrantes | Mejoran el contraste y evitan el estilo genérico de startup. |
| Cards 3x3 idénticas | Bento grid asimétrico con tamaños variados | Genera ritmo visual y jerarquía. |
| Todo centrado | Asimetría controlada, elementos que rompen el grid | Crea tensión visual e interés. |
| Fondos sólidos planos | Gradientes mesh, ruido, patrones, glassmorphism | Aportan profundidad y textura. |
| Lorem ipsum | Contenido realista con nombres, precios y features reales | Permite evaluar la jerarquía y credibilidad del diseño. |

## Reglas de oro adicionales

- Máximo 5–7 ítems de navegación para no saturar al usuario.
- Consistencia en bordes, sombras y paleta en toda la página.
- Touch targets de al menos 44×44 px en dispositivos móviles.
- Anima solo propiedades `transform` y `opacity` para mantener 60 fps.
- Mantén contraste WCAG AA (4.5:1) en texto normal.
